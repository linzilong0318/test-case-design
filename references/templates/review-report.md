# 测试用例评审报告模板

> 本文档定义「测试用例评审报告」的 Markdown 模板。在阶段三由 agent 对自己生成的用例进行自我审查后输出。

## 使用说明

1. **用例概况**：根据实际生成的用例进行统计
2. **覆盖度评审**：逐项检查需求覆盖情况，使用 ✅（通过）、⚠️（部分通过/需关注）、❌（未通过）
3. **质量评审**：按照 `references/templates/common-rules.md` 中的通用规则和 `references/checklists/` 中的检查清单逐项自查
4. **问题与改进建议**：如实记录自查过程中发现的问题
5. **评审结论**：给出客观的总评和可操作的改进建议
