## 零、测试用例可执行性检查（所有测试类型通用）

- [ ] 测试步骤中是否给出了具体的参数值/请求体/路径值（而非描述性语言）
- [ ] 是否存在"发送带错误参数的请求""输入异常数据"等不合格描述
- [ ] 请求参数是否给出了具体的 key=value 值
- [ ] 大量数据场景（如超大请求体、超长字符串参数）是否用描述性语言 + 明确参数说明

## 一、功能测试

- [ ] GET 请求正常返回
- [ ] POST 创建资源成功

- [ ] DELETE 删除成功
- [ ] 批量操作正确
- [ ] 状态码符合规范
- [ ] 错误响应清晰

## 二、状态码验证

- [ ] 200 OK 正常响应
- [ ] 201 Created 创建成功
- [ ] 204 No Content 删除成功
- [ ] 400 Bad Request 参数错误
- [ ] 401 Unauthorized 未认证
- [ ] 403 Forbidden 无权限
- [ ] 404 Not Found 资源不存在
- [ ] 409 Conflict 资源冲突
- [ ] 422 Unprocessable 校验失败
- [ ] 500 Internal Error 服务器错误
- [ ] 错误码规范统一
- [ ] 错误信息与状态码语义一致

## 五、安全测试

- [ ] SQL 注入防御（参数化查询验证）
- [ ] NoSQL 注入防御
- [ ] 命令注入防御
- [ ] 水平越权防护（IDOR，修改资源 ID 访问他人数据）
- [ ] 垂直越权防护（普通 Token 访问管理接口）
- [ ] 批量赋值防护（请求体中添加只读字段如 role、isAdmin 是否被拒绝）
- [ ] API 限流（>100 次/秒是否返回 429）
- [ ] 敏感信息防泄露（响应中不返回密码哈希、Token、内部 IP 等）
- [ ] 错误堆栈不暴露框架版本
- [ ] 安全响应头检查（X-Content-Type-Options、X-Frame-Options、CSP、HSTS）
- [ ] JWT 安全（alg=none 拒绝、过期 Token 拒绝、篡改 Payload 检测）
- [ ] 参数污染防护（重复参数、数组注入、HTTP Parameter Pollution）
